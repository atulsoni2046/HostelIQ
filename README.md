HostelX — Smart College Hostel Management System
==================================================

WHAT'S INSIDE
- index.html   → the full app (single file, no build step needed)

RUN IT LOCALLY
Just double-click index.html to open it in your browser.

HOST IT FOR FREE (recommended: Netlify or Vercel)
1. Go to https://app.netlify.com/drop
2. Drag this folder (or just index.html) into the browser window
3. You'll get a live URL in seconds — share it with anyone

Alternative: Vercel (https://vercel.com/new) — same idea, drag and drop,
or connect a GitHub repo containing this file.

NOTE ON DATA
All data (students, complaints, fees, etc.) currently lives in the
browser's memory — it resets on every page reload and isn't shared
between visitors. To make data persistent and multi-user, you'll need
a real backend (Node/Express + a database like PostgreSQL) — ask
Claude to build that next when you're ready.
